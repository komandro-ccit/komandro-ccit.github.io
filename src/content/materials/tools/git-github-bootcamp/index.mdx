# Git & GitHub Bootcamp

Materi lengkap Git & GitHub untuk **Basic Bootcamp Komandro 2026**. Pelajari dari nol: kenalan dengan Terminal, instalasi Git, sampai alur kerja tim pakai Pull Request dan merge conflict.

## Apa yang Akan Kamu Pelajari

- **Terminal**: Kenalan dengan aplikasi yang bakal sering dipakai
- **Git & GitHub**: Pengertian dan perbedaannya
- **Instalasi**: Install Git, buat akun GitHub, konfigurasi identitas
- **Konsep Dasar**: Repository, commit, branch, merge, staging area
- **Alur Kerja**: Add, commit, push
- **Branching**: Kerja paralel tanpa saling ganggu
- **Pull Request & Code Review**: Mengajukan dan mereview perubahan
- **Merge Conflict**: Menangani konflik antar branch
- **Fitur GitHub & Simulasi Kerja Tim**: Fitur GitHub plus latihan end-to-end
- **Cheat Sheet & Glosarium**: Referensi cepat perintah dan istilah

## Prerequisites

- Laptop dengan Git yang sudah terinstall (atau siap install di lesson 03)
- Akun GitHub (daftar di lesson 03)
- Koneksi internet stabil
- Rasa penasaran yang besar!
